# seances/ — les séances et cycles préparés

`collectif/` pour les cours, `individuel/` pour les séances d'une personne (elles contiennent
une note de santé et ne servent jamais aux publications). Un fichier par séance, nommé par la
date de la séance, ou un dossier par cycle. Claude les écrit avec `/creer-seance` à partir de
`contexte/methode.md`. Quand tu modifies une séance, dis-le-lui : il met à jour ta méthode.
