# ressources/ — une fiche par mail ou document reçu

Chaque chose qui entre (mail, message, document, facture, export, note dictée) a ici une fiche
courte qui dit de quoi il s'agit sans rouvrir l'original. C'est ce que Claude relit pour
retrouver une information.

- Un dossier `AAAA-MM-JJ_<sujet>/` par source, avec `fiche.md` et l'original s'il est en texte.
- Une fiche seule `AAAA-MM-JJ_<sujet>.md` suffit pour un message court.
- Le modèle est `_template-fiche-ressource.md`. S'il manque un champ utile à ton activité,
  demande à Claude d'étendre le modèle.
- Une fiche renvoie vers le dossier de la personne concernée, elle ne recopie rien.
