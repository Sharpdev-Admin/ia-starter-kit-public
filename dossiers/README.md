# dossiers/ — une fiche par personne

| Sous-dossier | Qui | Modèle |
|---|---|---|
| `prospects/` | toute personne qui a demandé une information ou un essai | `_template-fiche-prospect.md` |
| `membres/` | toute personne inscrite, active ou non | `_template-fiche-membre.md` |
| `fournisseurs/` | salle, matériel, assurance, logiciel | `_template-fiche-dossier.md` |
| `partenaires/` | autres clubs, entreprises, collectivités | `_template-fiche-dossier.md` |

Une fiche renvoie vers les documents de `ressources/`, elle ne les recopie pas. Claude crée et
met à jour ces fiches lui-même ; tu n'as rien à ranger.
