# session_reviews/ — un compte rendu par fin de session

`/eos` écrit ici un fichier `AAAA-MM-JJ_HH-MM_reviewed.md` par session : ce qui a été fait, ce
que tu as corrigé, les leçons proposées et celles que tu as acceptées.

Si tu réponds « plus tard », le brouillon est gardé en `..._pending.md` et repris à la session
suivante. Les règles retenues sont dans `../lessons.md`.
